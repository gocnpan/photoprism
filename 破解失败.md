## 从权限校验入手
在[navigation.vue](frontend/src/component/navigation.vue#L987)中`this.$config.allow("users", "manage")`校验是否拥有多用户管理页面

在[config.js](frontend/src/common/config.js#L382)中
```js
  allow(resource, perm) {
    if (this.values["acl"] && this.values["acl"][resource]) {
      if (this.values["acl"][resource]["full_access"]) {
        return true;
      } else if (this.values["acl"][resource][perm]) {
        return true;
      }
    }

    return false;
  }
```
`full_access`或`manage`字段为true时，表明用户有多用户管理权限

在[api_client_config](internal/api/api_client_config.go#L20)是api`/api/v1/config`的方法

从`conf.ClientSession`方法中`c.ClientUser(false).ApplyACL(acl.Rules, sess.UserRole())`可以看出`Session`直接关系到用户权限
